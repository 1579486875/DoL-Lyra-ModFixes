## 本模组的性质

本模组是 **Degrees of Lewdity** 的独立扩展，**不包含**游戏本体的任何代码或资源。

它只做一件事：读取游戏已有的状态变量，根据它们追加少量副作用（压力 / 创伤 / 名声 / 性奋）
与旁白文本。**不修改**游戏的任何原有逻辑、渲染、战斗公式或存档结构。
