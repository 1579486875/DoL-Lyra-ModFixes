### 为什么 i18n 没覆盖

```js
// 服装：只有 name/name_cap 有 cn_name（运行时注入），description 没有
new ClothesItem({
    name: "nightgown",
    description: "A basic sleep gown.",   ← 英文，无 _CN 字段
})

// 成就：title/desc/hint 全是英文
"A Crime Most Foul": {
    title: "A Crime Most Foul",
    desc: "Once late, forever shamed.",
    hint: "Hint: Make a written punishment permanent.",
}
```

**`_CN` 后缀字段全库只有 3 处** —— 说明这些 JS 里的文本**从未被翻译过**。

`ModI18N` 只处理 `.twee` 里的文本，**`<script>` 标签里硬编码的 JS 对象不在它范围内**。

### 关键实现：限定在 `setup.feats` 块内

`title:` 这个字段名**在别处也有**（如 `setup.NPCTitleList`）。直接全局替换会误伤。

```python
# 1. 定位 setup.feats = { ... } 块（花括号配对）
m = re.search(r"setup\.feats\s*=\s*\{", data)
i = m.end(); depth = 1
while i < len(data) and depth > 0:
    if data[i] == "{": depth += 1
    elif data[i] == "}": depth -= 1
    i += 1
block = data[m.start():i]          # 51120 字符

# 2. 只在块内替换
block = block.replace('title: "英文"', 'title: "中文"')

# 3. 拼回
data = data[:m.start()] + block + data[i:]
```

**校验结果**：
```

共替换 256 / 256 个
校验: title 共 256 个，其中中文 256 个，英文 0 个  ✅
```
