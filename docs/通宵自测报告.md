## 二、这轮最重要的事：**真的把游戏跑起来了**

之前所有轮次都是静态分析（正则、对比文件），**这轮第一次用真浏览器验证**。

### 方法

用 **Edge headless + CDP 调试协议**，Node 原生 `fetch` + `WebSocket`（**不需要装任何 npm 包**）：

```
cdp_test.js       加载 index，捕获所有 console/异常
cdp_probe.js      轮询等待就绪，执行任意探针表达式
cdp_apk_test.js   从 APK 提取 index + 起 HTTP + 测试 + 错误分组
```

### 关键坑：`file://` 测不了

`file://` 协议下 ModLoader 的 `fetch` 被拦（`TypeError: Failed to fetch`），
游戏**永远卡在 Loading**，`setup`/`State` 都不存在。

**必须起一个 HTTP 服务器**。这一条卡了我好几轮。

### 最隐蔽的两个

**#3 `NPC_CN_TYPE`**：模组（NpcNameCN）在 `storyready` 之后**覆盖**我的实现，
它内部的 `TITLES` 表只有职业词，没有野兽名。
**解法**：用 `Object.defineProperty` 的 getter/setter **锁定**：

```javascript
Object.defineProperty(st, name, {
    configurable: true,
    get: function () { return HOLDER[name].fn; },   // 我的包装函数
    set: function (v) {                             // 模组覆盖时
        HOLDER[name].orig = v;                      // 只更新内部 orig
        HOLDER[name].fn = makeFn(name);             // 重建但保留兜底
    }
});
```

**效果**：模组的表优先（`human→人类`），翻不出来的用我的补充表（`lizard→蜥蜴`）。

**#10 `cheatsBody`**：`_bodyTypes = ["男性化","女性化","中性化"]` 被翻译后，
`charAt(0)` 返回 `"男"` 而不是 `"m"`，存进 `$player.gender_body`。
而 JS 里有 **15+ 处** `=== "m"` / `!== "f"` / `{a:..,f:..}[gender_body]`。
**后果**：体型选择器永不高亮、服装性别判定失效、模型映射失效、bimbo/pimp 体型迁移失效。
**解法**：显示用中文数组，存储用独立的 `_bodyKeys = ["m","f","a"]`。

## 五、方法论沉淀（按有效性排序）

1. **「定义 vs 调用」全量对比** → 抓出 6 个缺失宏（含 86 次的 `printNobody`）
2. **CDP 真浏览器探针** → 能问游戏「这个宏在不在」「这个函数返回什么」
3. **widget 名对比**（modded vs vanilla）→ 抓出 `flight_text`
4. **变量名对比** → 抓出 `$compoundWraith`
5. **CSS class 对比** → 抓出 `cheatsBody`
6. **静态 JS 编译检查** → 抓出 `_DESC` 逗号

**共同点：都是「modded 独有 / vanilla 独有」的差异检测。**

### 三个审计工具本身的陷阱

| 陷阱 | 表现 | 正确做法 |
|---|---|---|
| **正则吞中文** | `$_ly和<<...>>` 被当成变量名 `$_ly和` | 变量名用 `[A-Za-z_][A-Za-z0-9_]*`，**别用 `\w`** |
| **剥离 `<script>` 会漏** | `$pubnpc` 被误报「modded 没有」 | 用 `\$name\b` 全文搜确认 |
| **只改一边** | `{m:'m'}` 改了但 `charAt(0)` 仍返回中文 | **「存什么」和「比什么」必须同时改** |
