# 诊断结论：农场「猪人」措辞

**日期**：2026-11-23
**结论**：**不是翻译错误**，是原版设计的「兽人化」机制。

---

## 一、现象

玩家在艾利克斯的农场看到：

> **猪人**在泥土里翻找着剩余的食物。

## 二、原文对照

| 文件 | 英文原文 | 当前译文 |
|---|---|---|
| `farm_text_many` | `pigpeople` | 猪人 |
| `farm_text_many` | `dogpeople` | 犬人 → **已统一为「狗人」** |
| `farm_text_many` | `cattle`（兽人化分支） | 牛 |
| `farm_text_neutral` | `pigperson` | 猪人 |
| `farm_text_neutral` | `dogperson` | 狗人 |
| `farm_text_neutral` | `cowperson` | 奶牛人 |

## 三、原版代码里的官方注释

```twee
<!-- No change for horses and cattle. 
     Pigs, dogs, and cows get called "pigperson", "dogperson", and "cowperson". -->
<<widget "farm_text_neutral">>
```

**意思**：
- **马**（horse）和**牛**（cattle）的称呼**不随兽人化改变**；
- **猪、狗、牛（cow）**会变成 `person` 形式，即「猪人」「狗人」「奶牛人」。

**所以这些译法全部符合原版意图。**

## 四、触发条件

```twee
<<set $_bperson to ($farm_work[_args[0]].monster_roll is true 
                    and ($hallucinations gte 1 or !$settings.monsterHallucinationsOnly))>>
```

即：**该动物被判定为「兽人化」**，且**玩家处于幻觉状态 或 没开「只在幻觉时显示兽人」的设置**。

游戏里的作弊/设置菜单有一项：

```
把野兽变为兽人
→ <<set $settings.monsterChance to 100>>
→ <<set $settings.monsterHallucinationsOnly to false>>
```

**开了这一项，农场里所有猪、狗、牛都会显示成兽人形态。**

## 五、本轮实际修复

**唯一发现的真问题：术语不统一。**

- `dogpeople`（复数）译成「**犬人**」
- `dogperson`（单数）译成「**狗人**」

同一概念两个词，且「犬人」与「猪人」「奶牛人」风格不一致（后者都用口语动物名）。

**修复**：把 2 处「犬人」统一为「狗人」。

**复查**：猪人 7 处 / 狗人 4 处 / 犬人 0 处 / 奶牛人 1 处。

## 六、可选的进一步优化

如果用户觉得「猪人」仍别扭，可考虑：

| 方案 | 效果 | 取舍 |
|---|---|---|
| 保持「猪人」（现状） | 忠实原文，与「狗人」「奶牛人」系列一致 | 单看略怪，但在句子里通顺 |
| 改「猪兽人」 | 更明确是兽人化 | 与「狗人」「奶牛人」风格不一致 |
| 改「猪头人」 | 形象直观 | 与其它词不成系列 |

**建议保持现状**，因为整组词（猪人 / 狗人 / 奶牛人）是成体系的。
