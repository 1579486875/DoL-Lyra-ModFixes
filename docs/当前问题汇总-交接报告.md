### 4. 签名问题
- ⚠️ 修改APK后必须重新签名
- ⚠️ 签名后 A.sig_sha256 测试会失败，这是正常的（可以豁免）
- ✅ 签名命令：
  ```powershell
  $pass = Get-Content "work\keystore.local" -Raw
  java -jar uber-apk-signer.jar --apks <apk> --ks dol_sha256.jks --ksAlias dol --ksPass $pass.Trim() --ksKeyPass $pass.Trim() --allowResign --overwrite
  ```

### 5. 不要在PowerShell里处理含尖括号的文件
- ❌ `Set-Content` 会把 `<` 写成 `A`
- ✅ 用Python的 `open().write()` 处理XML和HTML
