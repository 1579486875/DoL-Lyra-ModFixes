# 与社区汉化仓库的对比（只读调研，未向对方仓库发任何 issue / PR / 评论）

对象：[Eltirosto/Degrees-of-Lewdity-Chinese-Localization](https://github.com/Eltirosto/Degrees-of-Lewdity-Chinese-Localization/)
调研方式：GitHub API 只读查询（仓库信息、文件列表、Release、Issue 正文与截图），下载其 Release 资产做逐字节对比。

## 1. 对方仓库是什么

| 项 | 内容 |
|---|---|
| 性质 | **只做发布**：仓库里只有 `README.md` / `CREDITS.md` / `LICENSE` / `.data/`（3 张教程截图）/ `.github/`，**没有汉化源文件** |
| 许可 | **CC BY-NC-SA 4.0**（署名-非商业-相同方式共享）；README 另要求「严禁商业盈利或公开大肆传播」 |
| 最新发布 | `v0.5.12.13-chs-1.0.1a`（2026-10-02） |
| 发布资产 | `DoL-ModLoader-0.5.12.13-v2.101.1(.APK/.zip/-polyfill)`、`GameOriginalImagePack-0.5.12.13.mod.zip`、`ModI18N-0.5.12.13-chs-1.0.1a.mod.zip` |
| 构建源 | 汉化模组由 [NumberSir/DoL-I18n-Build](https://github.com/NumberSir/DoL-I18n-Build)（MIT）自动构建；该仓库已有 `0.5.13.5 ~ 0.5.13.8` 的 nightly，但**游戏版本是 0.5.13.x，与我们的 0.5.12.13 底包不兼容** |

## 2. 与我们的差异

| 维度 | 社区发布版 | 我们的整合包 |
|---|---|---|
| 汉化包 ModI18N | `1.0.1a` | **同一个 `1.0.1a`，27 个文件逐字节一致**（`AJ01_cmp_modi18n.py`） |
| 汉化方式 | 运行时由 ModI18N 替换 | 构建期把 passage 译文与 **JS 译文（第12轮起）** 预先烘焙进 index，运行时 ModI18N 仍在 |
| 第三方模组 | 不含 | 56 个模组（含 DoLSims / DomRobin / maplebirch / 枯木逢春 等）+ 我们自制的修复模组 |
| 安卓包 | ModLoader 空壳 APK，需手动导入汉化与图片包 | 全部内嵌，装好即玩；`resources.arsc` STORED + SHA256withRSA（鸿蒙可装） |
| 对已知汉化 bug 的处理 | 等月更发布 | 构建脚本逐条修复 + 回归断言 |

**结论：在 0.5.12.13 这个版本上，社区没有比我们更新的汉化文本可吸收**（汉化包完全相同）。
可吸收的是**他们 issue 区里用户报告的 bug** —— 逐条核对如下。

## 4. 吸收方式说明

- 没有复制对方的任何文件或文字。全部修复都是我们自己定位根因后写的构建脚本（`AI01` / `ZZ01` 修正等），
  只是借用了他们 issue 里用户提供的**现象描述与截图**来确认问题。
- 若将来要把我们的修法回馈给社区，`AI01` 的「显示值兼作逻辑值」清单和 `#582` 的根因说明可以直接整理成 issue —— **按要求本轮没有发出**。
- 若将来要跟进 0.5.13.x：需要先升级 DoL-Lyra 底包，再用 NumberSir/DoL-I18n-Build 的新 ModI18N，
  我们的 100+ 条构建脚本与 REGRESS / RT_GATE 断言需要整体重跑一遍。
