### 3.2 食物联动（More-Useful-Foodstuff → BasicNeeds）

**问题**：More-Useful-Foodstuff 有独立的饱食度/消化系统，**不写 BasicNeeds 的 `$BasicNeeds.hunger/thirst`** → 吃了它的食物，原版饥饿/口渴条不动。

**修法**：在它的 `eat()` 里插入桥接（`vars[INTAKE_KEY] = ...` 之后）：

```js
const _bn = (window.SugarCube && SugarCube.State && SugarCube.State.variables)
    ? SugarCube.State.variables.BasicNeeds : null;
if (_bn) {
    const _cost = Number(check.cost) || 15;
    _bn.hunger = Math.max(0, (_bn.hunger || 0) - _cost * 80);
    _bn.thirst = Math.max(0, (_bn.thirst || 0) - _cost * 30);
}
```

**验证**（CDP 实调 `setup.FoodEffectsExpanded.eat("apple")`）：

```
before: hunger 8000 / thirst 8000
after : hunger 6800 / thirst 7550   （cost 15 → -1200 / -450）
result: ok:true，"你吃下了苹果，感觉恢复了些精神。"
```
