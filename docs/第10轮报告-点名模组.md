## 三、NoTraumaClamp 的修复细节

**原补丁**（ReplacePatcher，`stat-changes.js`）：

```json
{"from": "if (V.trauma >= V.traumamax) V.beauty -= (V.trauma - V.traumamax) / 5;",
 "to":   "if (V.trauma >= V.traumamax) V.beauty -= 0 ;"}
```

**当前版本实际代码**（`traumaClamp` 宏内）：

```js
const overflow = V.trauma - V.traumamax;
if (overflow > 0) {
    // Remove 20% of the overflow from the player's beauty.
    V.beauty -= overflow * 0.2;
}
```

**修法**：直接改 index（`V.beauty -= overflow * 0.2;` → `V.beauty -= 0;`），并移除失效的 NoTraumaClamp 模组。

**验证**（CDP）：`trauma = traumamax + 100`、`beauty = 50` → 调用 `<<traumaClamp>>` → **beauty 仍为 50**（改前会降到 30）。
