## 六、根本教训

### build_all.py 第 1 步会重建 index

inject6.py 从源文件重新生成 index_modded6.html，
**所有手工修复必须做成幂等脚本加进 build_all**，否则下次构建就没了。

这解释了为什么前几轮「修好了但又坏了」。

### index.html 的真实形态

- passage 标签：**明文** <tw-passagedata name=...>
- passage 内容：**HTML 转义** &lt;&lt;if $x&gt;&gt;

**任何 html.escape() 整文件的操作都会毁掉它**（导致 0 passage / 白屏）。

### 判据优先级

| 判据 | 可靠性 |
|---|---|
| **CDP 真机实测** | 最高 |
| 对比基线（0A316E37） | 高 |
| 静态正则扫描 | 中（易误报） |
| 记忆印象 | **不可用**（用户明确禁止） |
