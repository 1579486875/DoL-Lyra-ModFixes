## 本轮修复（共 6 类）

### 1. 运算符 `&&` 被翻成「且」（致命）

```
原：&lt;&lt;if $audience gte 0 且 $audience lte 5&gt;&gt;
改：&lt;&lt;if $audience gte 0 and $audience lte 5&gt;&gt;
```

→ `SyntaxError: Unexpected identifier '且'` → `danceaudience` 崩 → `personselect` 连锁报错 100+ 条。

### 2. 标识符被翻成中文（致命，18 处）

| 错 | 正确 |
|---|---|
| `<<set _下体。integrity -= 10>>` | `<<set _lower.integrity -= 10>>` |
| `<<if C.npc.罗宾。trauma gte 50>>` | `<<if C.npc.Robin.trauma gte 50>>` |
| `<<elseif C.npc.艾弗里。rage gte 20>>` | `<<elseif C.npc.Avery.rage gte 20>>` |
| `<<elseif $bird.火坑前面。items.length gte 1>>` | `<<elseif $bird.firepit_front.items.length gte 1>>` |
| `<<if $ene我的arousal gte $enemyarousalmax>>` | `<<if $enemyarousal gte $enemyarousalmax>>` |
| `<<elseif $skin.额头上。special isnot "island">>` | `<<elseif $skin.forehead.special isnot "island">>` |
| `<<set _items = applyClothingShop过滤(_items)>>` | `<<set _items = applyClothingShopFilter(_items)>>` |

**注意**：之前的 `EXTRA` 表加到了 polyfill 库的 `EXTRA_ARGS_SUPPORT` 上（正则误匹配），全部无效。

### 4. `Widgets Repair` passage 丢失（50775 字符）

`ADI01_safe_passage.py` 每次运行都先删旧的再重建，重建失败就丢。
已恢复，并给它加了「先备份到 `_widgets_repair_backup.txt`」的逻辑。

### 5. JS 硬编码英文 152 + 28 条

`element("span", "...")` 里的身体变化提示（`Your eyes itch.` → `你的眼睛发痒。` 等）。
