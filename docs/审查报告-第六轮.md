## 问题性质

**翻译工具把英文标识符翻成了中文**，直接造成 JS 语法错误：

| 原文（错） | 正确 |
|---|---|
| `<<set _下体。integrity -= 10>>` | `<<set _lower.integrity -= 10>>` |
| `<<if _下体。plural isnot 1>>` | `<<if _lower.plural isnot 1>>` |
| `<<if C.npc.罗宾。trauma gte 50>>` | `<<if C.npc.Robin.trauma gte 50>>` |
| `<<elseif C.npc.艾弗里。rage gte 20>>` | `<<elseif C.npc.Avery.rage gte 20>>` |
| `<<elseif $bird.火坑前面。items.length gte 1>>` | `<<elseif $bird.firepit_front.items.length gte 1>>` |
| `<<if $ene我的arousal gte $enemyarousalmax>>` | `<<if $enemyarousal gte $enemyarousalmax>>` |
| `<<elseif $skin.额头上。special isnot "island">>` | `<<elseif $skin.forehead.special isnot "island">>` |
| `<<set _items = applyClothingShop过滤(_items)>>` | `<<set _items = applyClothingShopFilter(_items)>>` |
| `<<set _modeloptions.tanning启用d to false>>` | `<<set _modeloptions.tanningEnabled to false>>` |
| `{ prop: "price", 次序: 'asc', enabled: false }` | `{ prop: "price", order: 'asc', enabled: false }` |
| `<<switch Math.clamp($_精液， 1, 5)>>` | `<<switch Math.clamp($_semen, 1, 5)>>` |
| `<<set $speech冲撞着entrance to 1>>` | `<<set $speechrammalentrance to 1>>` |

**关键特征：英文的点号 `.` 被翻成了中文句号 `。`**

---

## 判据（供以后复用）

在 `<<if>>` / `<<elseif>>` / `<<set>>` / `<<run>>` / `<<switch>>` / `<<case>>` 内部：

1. **挖掉字符串字面量** `"..."` `'...'` `` `...` `` 和正则字面量 `/.../`
2. **剩余部分如果还有中文字符** → **就是代码位置被污染**

这个判据能精确区分：
- ❌ `<<if C.npc.罗宾。trauma gte 50>>`（代码位置）
- ✅ `<<set _output += "而且<<possessedWord '你的'>>">>`（字符串内，正常）
