## 一、问题

用户发现侧栏有「勇气 / 镇静 / 欲望 / 满足」四个状态，但两个作弊菜单都找不到对应调试项。

**定位结果**：四个状态全部来自 **露出拓展（MyExhibitionismExpansion 1.0.4）**。

| 状态 | 类型 | 变量 / 函数 |
|---|---|---|
| **欲望** | 真实变量 | `V.desire`，0–1000，默认 500 |
| **满足** | 真实变量 | `V.satisfaction`，0–1000，默认 300 |
| **勇气** | **派生值** | `mee.courage()` |
| **镇静** | **派生值** | `mee.calm()` |

**派生公式**：

```
勇气 = 满足 × clamp(1 + (欲望-500)/500 + 醉酒/1000×2, 0)
镇静 = 满足 × clamp(1 - (欲望-500)/500 - 醉酒/1000×1, 0)
```

`欲望` 每分钟自然 -0.1。

---

## 二、为什么作弊菜单找不到

1. **原版「状态」页**（`<<widget "cheatSection">>` 的 `case "state"`）只列**原版状态变量**（疼痛/性奋/疲劳/压力/创伤/自控力/醉酒/药物/致幻/饥饿/口渴/脏污度/心情/牙齿/头发），`$desire` / `$satisfaction` 是模组私有变量，不在其中。
2. **「模组作弊」页**由 MapleBirchCE 提供，靠 `setup.mbCE_modCheats` / `CHEAT_ADAPTERS` / `CHEAT_PASSIVE_PROBES` 三通道发现。**露出拓展没有注册**，所以不出现。
3. **勇气/镇静** 是函数算出来的派生值，**没有存储位置**，即使加了控件也会被重算覆盖。

---

## 三、修复：给 MapleBirchCE 加适配器

在 `javascript/maplebirchce.js` 的 `var CHEAT_ADAPTERS = {};` 之后插入：

```js
CHEAT_ADAPTERS["my-exhibitionism-expansion"] = {
    detect: function () {
        try {
            return typeof window.mee === "object" && !!window.mee
                && typeof window.mee.setDesire === "function";
        } catch (e) { return false; }
    },
    entry: {
        modId: "my-exhibitionism-expansion",
        modName: "露出拓展 v1.0.4",
        tasks: [], stages: [], abilities: [], scenes: [],
        values: [
            { key: "mee_desire", name: "欲望", varPath: "desire", type: "number", min: 0, max: 1000,
              note: "0-1000，默认 500。越高：勇气↑、镇静↓；每分钟自然 -0.1。" },
            { key: "mee_satisfaction", name: "满足", varPath: "satisfaction", type: "number", min: 0, max: 1000,
              note: "0-1000，默认 300。勇气/镇静的基础值，满足高则两者都高。" }
        ],
        actions: []
    }
};
```

**为什么用 `values` 而不是 `numberStepper`**：
- 模组作弊页统一走 `maplebirchce.js` 自己的 `buildCheatValueRow()` 渲染（文本输入 + `应用修改` + `回退` + 说明折叠）。
- 原版状态页的 `<<numberStepper>>` 是原版 Twee 组件，模组作弊页没有引入。
- 功能等价：支持绝对值与 `+N` / `-N` 相对调整、写入前校验、回退还原。

**为什么没有加勇气/镇静**：派生值无存储位置，写了会被 `mee.courage()` / `mee.calm()` 重算覆盖。
