## 〇、调研结论（决定"能做什么"）

### 已验证的事实

| 项 | 事实 | 影响 |
|---|---|---|
| **需求上限** | `MAX = 10000` | 所有阈值按此比例 |
| **口渴速率** | `2000/h`（0→7000 用 3.5 小时） | 很急 |
| **尿意速率** | `1333/h`（膀胱 300ml） | 7.5 小时满 |
| **清洁速率** | `150/h`（睡 8h = 1200 发臭） | 慢 |
| **温度分档** | 口渴：热×1.5 / 冷×0.8；膀胱：热×0.7 / 冷×1.3 | **已有，不动** |
| **雨天** | 未撑伞变脏 ×2 | **已有，不动** |
| **失禁** | `bladderFullHrs >= 1` → `accident()` | **有，但只弄湿衣服** |
| **大便** | **没有失禁**，满值后 `applyStrain` 加压/痛 | 设计联动时要区别对待 |
| **暴露宏** | `<<exhibitionist n>>` 只是**显示**"露出癖 N 级" | **不是增加函数** |
| **暴露场景** | `<<exhibitionism "street"/"alley">>` 按 `$uncomfortable.nude` + `$exposed` + 昼夜生成文本 | 成熟 |
| **羞耻维度** | `$uncomfortable` 有 6 个：`nude` / `flaunting` / `lewd` / `underwear` / `prostituting` / `hypnosis` | 可精细控制 |
| **名声** | `$fame.exhibitionism`（0–2000，`Math.clamp`） | 有上限 |
| **怀孕** | `$pregnancies`（数组）+ `getActivePregnancy()` | 不是 `$pregnancy` |
| **战斗** | `<<physiquedifficulty 6000 15000>>` / `<<physique_loss N>>` | 改这些宏风险高 |
| **摄影** | 原版是 `$photo`（尼奇摄影棚），手机是 `$Phone.photography` | 两套 |
| **`isSafe`** | 是 lodash 的 `isSafeInteger`，**不是**私密场所判定 | 误报，排除 |

### 因此排除的方案

| 方案 | 排除原因 |
|---|---|
| **天气→需求** | **已有**（温度分档 + 雨天 ×2） |
| **转化→需求/服装** | **用户明确不要** |
| **改 `physiquedifficulty` 全局** | 调用点太多（1100 处 physique），改一处漏十处 |
| **改渲染层 `$exposed`** | 原版每帧计算，硬改会打架 |
| **用 `isSafe` 判私密** | 是 lodash 函数，误报 |

## 一、要做的 5 组联动

### 联动 1：失禁 → 羞耻 / 名声 ⭐ 低风险

**触发**：`$BasicNeeds.bladder` 从 `>= 9000` 突然变成 `0`（说明刚失禁）

**判定公共场合**：`$exposed >= 1`（当前处于暴露状态）或 `$location` 属于公共区

**效果**（分三档）：

| 条件 | 效果 |
|---|---|
| 私密/无人（`$exposed` = 0 且 `$uncomfortable.nude` = false） | `$stress += 50`，无名声 |
| 公共但不在意（`$uncomfortable.nude` = false） | `$stress += 150`，`$fame.exhibitionism += 2`，`$arousal 20` |
| 公共且羞耻（`$uncomfortable.nude` = true） | `$stress += 400`，`$trauma += 1`，`$fame.exhibitionism += 5` |

**文本**（按档位，写色）：

> **档 1（私密）**
> 腿间一热，你没能忍住。温热顺着大腿内侧淌下来，把内裤洇成深色的一片。好在四下无人，只有你自己闻得到那股味道。

> **档 2（公共·不在意）**
> 一股热流不受控制地涌出，顺着腿根往下淌。你没有急着遮掩，反而站定了，任由那股温热在内裤里逐渐变凉、变黏。湿透的布料贴着皮肤，每走一步都黏腻地厮磨。

> **档 3（公共·羞耻）**
> 你没能撑住。热流沿着大腿内侧淌下，滴在地上，留下一小滩深色的痕迹。有人看见了——你听见一声没忍住的轻笑。脸烧得厉害，可身体却在这种羞耻里泛起了异样的热度。

**实现**：`:passageend` 钩子，检测 `bladder` 跳变。

### 联动 2：服装破损 → 走光 ⭐⭐ 中风险

**触发**：某槽位 `integrity / integrity_max < 0.35`

**效果**：

| 破损程度 | 判定 |
|---|---|
| `>= 0.7` | 完好 |
| `0.35 – 0.7` | **半透**：`$stress += 20`/小时，暴露判定 +1 档 |
| `< 0.35` | **走光**：该槽位视为 `exposed`，`$fame.exhibitionism += 1`/小时 |

**文本**（半透）：

> 衣服磨得薄了，贴在身上几乎能看出底下的轮廓。风吹过来的时候，布料贴着皮肤凹陷下去，勾勒出不该被看见的形状。

**文本**（走光）：

> 那里已经裂开了一道口子，遮不住了。你一动，破口就翻卷开来，把底下的皮肤露在外面。凉意顺着那道缝隙钻进来。

**实现**：`:passageend` 钩子，扫描 `$worn` 各槽位。

**风险**：不改 `$exposed`（原版变量），只加 `$stress` 和 `$fame`，**不碰渲染**。

### 联动 3：需求 → 战斗表现 ⭐⭐ 中风险

**触发**：战斗开始时（`:passagestart` 且 passage 含 `Combat`）

**效果**（**只加惩罚，不加数值**）：

| 需求 | 效果 |
|---|---|
| 口渴 > 8000 | 战斗中每回合 `$stress += 30`，文本提示「喉咙干得发疼」 |
| 尿意 > 8000 | 战斗中每回合 `$stress += 50`，文本提示「小腹坠得厉害，你几乎站不稳」 |
| 饥饿（`digestHunger` 低） | 体力上限 -10%（通过 `$tiredness` 加） |

**文本**（尿意满）：

> 小腹涨得发疼，每动一下都有液体在里面晃。你夹紧腿，可这只会让那股胀意更清楚。对面的动作你几乎没看清——你满脑子只剩一件事：憋住。

**实现**：`:passagestart` 检测 + 战斗轮次钩子。

**风险**：`>` 不改战斗数值公式，只加 `$stress` / `$tiredness`，**安全**。

## 二、平衡设计（数值依据）

### 参考基准

| 原版数值 | 值 | 用途 |
|---|---|---|
| `$stress` 上限 | 通常 200 | 我们加 50–400，**注意不要一击致崩** |
| `$trauma` | 0–? | 加 1–2，**很轻** |
| `$fame.exhibitionism` 上限 | 2000 | 加 1–5，**很轻** |
| 需求 MAX | 10000 | 阈值 8000/9000 是"很急" |
| `integrity` 比例 | 0–1 | 0.35 是"快破了" |

### 平衡原则

1. **单次事件不致命**：`$stress` 单次最多 +400（原版上限 200，所以会到顶，但不会崩）
2. **名声增长慢**：一次失禁 +5，2000 上限 = 需要 400 次
3. **可开关**：所有联动做成模组，可在 ModLoader 禁用
4. **不影响原版核心**：只加 `$stress` / `$trauma` / `$fame` / `$tiredness`，**不改** `$exposed` / 战斗公式 / 渲染

## 三、实现方式

### 3.1 新建模组 `系统联动补全`

**结构**：

```
系统联动补全/
├─ boot.json
├─ scripts/联动核心.js      （检测 + 效果）
├─ twee/联动文本.twee       （文本片段）
└─ style/联动.css           （可选，颜色）
```

**依赖**：`ModLoader`、`BasicNeeds`（可选，缺失时降级）

### 3.2 关键技术点

**① 失禁检测**

`accident()` 是闭包内函数，不能直接 hook。改用**状态跳变**：

```js
let lastBladder = null;
$(document).on(':passageend', () => {
    const bn = V.BasicNeeds;
    if (!bn) return;
    if (lastBladder !== null && lastBladder >= 9000 && bn.bladder === 0) {
        onAccident();          // 判定到失禁
    }
    lastBladder = bn.bladder;
});
```

**② 不破坏存档**

所有状态存在 `V.联动` 下，加 `version` 字段，**升级时自动迁移**。

**③ 可降级**

`BasicNeeds` 不存在时，联动 1/3 自动禁用；`maplebirch` 不存在时，联动 5 禁用。

## 四、文本风格要求

用户要求「**写色点**」，具体原则：

| 原则 | 说明 |
|---|---|
| **写身体感受** | 温热、黏腻、坠胀、发凉、厮磨 |
| **写环境互动** | 风吹、布料摩擦、地面湿痕、旁人目光 |
| **写心理反差** | 羞耻 ↔ 兴奋、想遮 ↔ 不想遮 |
| **不写露骨器官名** | 用「腿间」「那股热」「底下」 |
| **控制长度** | 每次 2–4 句，不打断节奏 |
| **分档写** | 私密/公共 × 在意/不在意，四种语气 |

## 六、风险与回退

| 风险 | 缓解 |
|---|---|
| 联动触发太频繁 | 加冷却时间（同一联动 10 分钟内不重复） |
| `$stress` 顶满导致崩 | 单次上限 + 检测当前值 |
| 与现有模组冲突 | 独立模组，可单独禁用 |
| 存档不兼容 | 所有状态挂 `V.联动`，版本升级自动迁移 |

**回退**：删掉模组即可，**不改任何现有文件**。
