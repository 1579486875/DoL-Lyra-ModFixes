## 判据要点（踩过的坑）

### 反引号在 SugarCube 里不是 JS 模板字符串

- **普通 passage 文本**里的 `` `...` `` = **内联文本**，其中的 `$var` 只匹配 `[A-Za-z0-9_]`
  → `$x.cn_name_cap中文` 是**正常的**
- **只有 `<<script>>` / `<<run>>` 里的** `` `...` `` 才是 JS 模板，需要 `${}`

**一开始我按 JS 模板判据扫，误报 993 处**，逐步收紧到 12 → 4 → 最后确认全是误报。
最终判据改为「只查 F17 修过的 3 个已知模式」。

### `<<br` 会匹配 `<<breasts`

用 `<<br\s*>>` 而不是 `<<br`。

### 变量名含中文大量误报

`'1月_2月_3月'` 这种字符串的 `_` 分隔符会被当成变量名。
