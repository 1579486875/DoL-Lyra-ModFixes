## 五、本轮方法论收获

### 「探针返回 0」可能是「没跑」

第 8 轮我写：
```js
if (SugarCube.Story && SugarCube.Story.passages) { ... 遍历 ... }
```
`SugarCube.Story.passages` 是 undefined → **条件为 false → 整个循环跳过 → `argsLeak` 保持初始值 0**。

**看起来是「干净」，实际是「没检查」。**

**修正原则**：**探针必须同时返回「检查了多少个对象」**，否则 0 毫无意义。

### 正确的 SugarCube 2.36 API

| 想做的事 | 错误写法 | 正确写法 |
|---|---|---|
| 遍历 passage | `SugarCube.Story.passages` | **没有直接方式**；用 `Story.has(name)` / `Story.get(name)` 逐个查 |
| 查宏是否注册 | `SugarCube.macros[name]` | **`SugarCube.Macro.has(name)`** |
| 取宏源码 | `String(SugarCube.Macro.get(n))` | **不可行**（返回通用 wrapper） |
| 取 passage 原文 | `Story.get(n).text` | ✅ 可用，但对某些 passage 返回错误页 |
