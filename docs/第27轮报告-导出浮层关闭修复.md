## 一、问题

服装编辑器里点「导出」，弹出 JSON 文本框 + 提示「已复制到剪贴板（点任意处关闭）」。

**现象**：点**空白处**时，提示条消失，但**JSON 文本框还在**；只有点**文本框里的文字**才会一起消失。

## 二、根因

`exportOutfit`（index 内的 `window03-JavaScript/05-renderer/canvasmodel-editor.js`）的 `_fallback`：

```js
const close = function () {
    try { ta.remove(); hint.remove(); } catch (e) {}
    document.removeEventListener("click", close);
};
window.setTimeout(function () { document.addEventListener("click", close); }, 300);
```

**问题**：`click` 绑在 **`document` 的冒泡阶段**。

- 服装编辑器是 **overlay**，`maplebirch`/SugarCube 的 overlay 层在点击时会 `stopPropagation()`，事件**冒泡不到 document** → `close` 不执行 → 文本框残留。
- 提示条之所以消失，是因为它有独立的 `setTimeout` 或 CSS 过渡（用户观感上「提示没了、文本还在」）。
- 手机端 `touch` 事件与 `click` 时序不同，冒泡更易被拦。

## 三、修复

改成**捕获阶段** + **触摸事件** + **定时兜底**：

```js
let _closed = false;
const close = function (ev) {
    if (_closed) return;
    /* 点在文本区域内时不关闭，允许选中/长按复制 */
    if (ev && (ev.target === ta || (ta.contains && ta.contains(ev.target)))) return;
    _closed = true;
    try { ta.remove(); } catch (e1) {}
    try { hint.remove(); } catch (e2) {}
    document.removeEventListener("click", close, true);
    document.removeEventListener("touchend", close, true);
    document.removeEventListener("mousedown", close, true);
};
setTimeout(() => {
    document.addEventListener("click", close, true);
    document.addEventListener("touchend", close, true);
    document.addEventListener("mousedown", close, true);
}, 300);
/* 兜底：15 秒后无论如何收掉，避免残留挡住界面 */
setTimeout(() => { if (!_closed) { _closed = true; ta.remove(); hint.remove(); } }, 15000);
```

**三个关键改动**：

| 改动 | 作用 |
|---|---|
| `addEventListener(..., true)` | 捕获阶段监听，**不会被 overlay 的 stopPropagation 拦住** |
| 同时监听 `touchend` / `mousedown` | 手机端触摸优先，桌面端鼠标兜底 |
| `ta.contains(ev.target)` 判定 | 点在文本框**内部**时**不关闭**，允许选中/长按复制 |
| 15 秒定时兜底 | 极端情况下也不会永久残留 |
