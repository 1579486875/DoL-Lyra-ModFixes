### 1.1 NPC.Avatars 英文分支彻底中文化

**原状**：`bsa-check.twee` 用 `<<if ModI18N>>...<<else>>...<</if>>` 双分支，英文分支保留 7 句英文。若 `ModI18N` 判定失败就会露出英文。

**修复**：删掉 `<<if>>/<<else>>/<</if>>` 判断，**只保留中文分支**。

```twee

<<if window.modUtils.getMod('ModI18N')>>
    <mouse>...为什么没有图像？...</mouse>
<<else>>
    <mouse>...Why are there no images?...</mouse>
<</if>>

```

### 1.2 `more useful foodstuff` 帮助弹窗改捕获阶段

**原状**：`food-effects.js`

```js
document.addEventListener('click', outsideHelp);   // 冒泡阶段
```

在 overlay 或有 `stopPropagation` 的容器里，点击不会冒泡到 document，帮助弹窗关不掉。

**修复**：

```js
document.addEventListener('click', outsideHelp, true);          // 捕获阶段
document.removeEventListener('click', outsideHelp, true);       // cleanup 同步
```

**验证**：add / remove 各 1 处均已改。

## 二、未修的一项及理由

### DomRobin 链式补丁（静态误报，不动）

`Robin Hug Cry` 的三条补丁是**链式**的：

1. `find: '<<set $robincrycount to 0>>'` → `replace: '<<set $robincrycount to 1>>'`
2. `find: '<<if _robinlove gte 80 and $robincrycount gte 5>>'` → `replace: '...gte 2>>'`
3. `find: '<<if _robinlove gte 80 and $robincrycount gte 2>>'` → `replace: None`（删除）

第 3 条依赖第 2 条**执行后的结果**，静态逐条比对必然报失配。

**运行时 G2 = 0**（按顺序执行，无报错），功能正常。

**改动风险**：合并这些补丁需要重写模组的补丁意图（`replace: None` 到底是删整块还是删片段，静态无法确定），**改错会破坏 Robin 的哭泣对话分支**。收益（仅让静态审计好看）小于风险，**保持原样**。
