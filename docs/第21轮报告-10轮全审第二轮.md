## 二、本轮的关键发现

### 2.1 【严重·已修】`Npc Name CN` 模组覆盖了 bodyparts 表

**现象**：上一轮我给 index 的 `BODYPARTS_CN_NAME` 补了 `"right":"右"`，但**玩家侧仍然显示 `right`**。

**排查链**：

1. index 里有**两处**定义：
   - `st.BODYPARTS_CN_NAME = mk({...})`（旧，无 right）
   - `st.BODYPARTS_CN_NAME = function (x) {...}`（新，有 right）
2. 两处守卫名不同（`__i18nHelpersInstalled` vs `__cnTablesInstalled`），不会互相跳过。
3. **运行时抓函数体**：

```
function partCN(v) { return tr(BODYPARTS, v); }
```

**这是第三处定义** —— 来自模组 `Npc Name CN` 的 `npcNameCN.js`：

```js
function forceSetup() {
    // 强制接管：不判断是否已存在，避免被返回脏值的 shim 抢先
    st.NPC_CN_NAME      = nameCN;
    st.NPC_CN_TYPE      = typeCN;
    st.NPC_CN_TITLE     = titleCN;
    st.BODYPARTS_CN_NAME = partCN;      // ← 强制覆盖
    return true;
}
```

**它的 `BODYPARTS` 表有 76 条，但只有驼峰形式**（`leftHand`/`rightHand`），**没有空格/单词形式**（`right`/`left`/`right hand`）。

而 `combat-tug-clothing` 传的是 `"right"` —— 查不到，原样返回。

**修法**：在该模组的 `BODYPARTS` 表里补 8 条：

```js
"right": "右", "left": "左",
"right hand": "右手", "left hand": "左手",
"right foot": "右脚", "left foot": "左脚",
"right arm": "右臂", "left arm": "左臂",
```

**运行时验证**（CDP 实测）：

```
right      -> 右
left       -> 左
hand       -> 手
right hand -> 右手
foot       -> 脚
```

**教训**：**改 index 里的表可能被模组「强制接管」覆盖**。凡是被模组接管过的函数，必须改**模组内的表**才有用。
