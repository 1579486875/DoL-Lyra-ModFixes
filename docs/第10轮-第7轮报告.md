## 二、模组补丁健康度扫描（51 regex + 368 findString）

### 发现问题：8 处空 regexFlag —— 全在 `Quoted Link Fix`

```
[Quoted Link Fix] 'Bully Toilets Sex Finish'
  regex='[[(?:Next|继续)\|"School Boy\'s Toilets"]]'
```

**这个模组专门修「带引号的 link 目标」**，但因为 `regexFlag: ""` 导致
`new RegExp(pattern, "")` 失败，**8 条补丁全部失效**。

### 与第 3 轮基线对比的联动发现

第 3 轮我做基线对比时发现 `<<link>>` 目标缺失 30 个，其中：

```
'"School Boy\'s Toilets"' ×4
'"School Girl\'s Toilets"' ×4
```

**正是这 8 个！** 而 `Quoted Link Fix` 就是来修它们的 —— **补丁失效导致这 8 个死链一直存在**。

**修好后**：这 8 个 link 在运行时会由补丁改写掉引号，变成可跳转的正常链接。

### 修法

删掉 `regexFlag: ""` 字段（与 K17 修 `DoLSims` 同一手法）。

**验证**：`剩余空 regexFlag = 0` ✅
