## 一、自查发现的 4 个问题

### 🔴 问题 1：`inPublic()` 把「暴露程度」当成「地点」

**错误写法**：

```js
function inPublic() {
    if (PUBLIC_RE.test(currentPassage())) return true;
    return safe(function () { return V.exposed; }, 0) >= 1;   // ← 错
}
```

**为什么错**：`$exposed` 是**暴露程度**（0=穿着、1=半裸、2=全裸），不是地点。
在**自己家全裸**时 `$exposed = 2`，会被误判成"在公共场合"，导致失禁时触发最高档惩罚。

**修法**：

```js
function inPublic() {
    if (inOwnHome()) return false;      // 先排除自家
    return PUBLIC_RE.test(currentPassage());
}
```

**验证**：`1_在家裸体` → stress **+150** / fame **0**（修正前会走「公共羞耻」档 +1800/+5/+120）

---

### 🔴 问题 2：`inOwnHome()` 的正则太宽，误匹配作弊卡

**错误写法**：

```js
return /Deadwood Reblooms|Flats Own|Cottage|Manor|Estate/i.test(...);
```

`Estate` 会匹配 `Estate Cards Cheating Plead`（作弊卡牌场景），把作弊菜单当成"自己家"。

**修法**：改成只匹配确定的房产 passage

```js
return /Deadwood Reblooms|Flats Own (Room|Shower|Bath)|Orphanage Bedroom|Cottage Interior|Manor Bedroom/i.test(...);
```

### 🔴 问题 3：走光的名声会无限增长（**最严重**）

**错误写法**：

```js
if (worstRatio < 0.35) {
    if (cooling('tear_' + worst, 5 * 60 * 1000)) return;
    addStress(60);
    addFame(1);       // ← 每 5 分钟加一次
}
```

**后果**：衣服一直破着 → **一天 288 次 × fame +1 = +288**，上限 2000，**7 天刷满**。

**修法**：用标记控制，**同一次破损只加一次名声**

```js
var key = 'tearFamed_' + worst;
var famed = V.联动[key];
if (!famed) { addFame(1); V.联动[key] = true; }
// 衣服修好后重置标记，下次再破还能再计一次
```

**验证**：
- `2_走光首次` → fame **+1**
- `2_走光第二次` → fame **0**（仍然 +60 stress，因为持续走光确实难受）
