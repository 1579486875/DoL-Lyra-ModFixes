## 🔧 本轮修复内容

### BG31: 修复 loadFiltersMenu widget 的 _traitObj.name 逻辑漏洞

#### 问题描述
原版代码第 116 行存在逻辑漏洞：
```sugarcube
<<if !_traitObj or !_traitObj.desc>>
    <<print _traitObj.name>>
```

- 外层 if 判断了 `!_traitObj`（_traitObj 不存在）
- 但如果 _traitObj 是 undefined，内层的 `_traitObj.name` 会报错
- 虽然该问题可能从未实际触发（因为 setup.shopDetails 可能总是完整的），但仍是代码缺陷

#### 修复方案
按照模板 §5.9 的标准修法，加内层守卫：
```sugarcube
<<if !_traitObj or !_traitObj.desc>>
    <<if _traitObj>><<print _traitObj.name>><</if>>
```

#### 实现
- **脚本**：`BG31_fix_traitobj_guard.py`
- **修改位置**：`Widgets FilterShop` → `loadFiltersMenu` widget
- **变更**：1 处（第 116 行）
