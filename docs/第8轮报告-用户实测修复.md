## 二、逐项根因与修法

### 1. `props/undefined/*.png`（①/②保意图）

**根因**：`wearProp()` 里

```js
T.prop = Object.assign({}, setup.propDefaults, propErties, {...})
```

`setup.propDefaults` 由 `initProps()` 建立。**只要某条路径下 `initProps()` 没跑到 / 被模组覆盖成 undefined**，
`Object.assign` 会静默跳过 undefined，`folder` 就没了 → 图片路径变成 `props/undefined/soap.png`。

**判据**：CDP 里 `!!setup.propDefaults`；以及 APK 内 `img/clothes/props/general/{soap,toothbrush,toothbrush-acc}.png` 三张图都在（实测都在）。

**修法（②兜底）**：

```js
T.prop = Object.assign({}, (setup.propDefaults || {
  folder: "general", armPosition: "right_hold", animation: "idle", zIndex: "handheld"
}), propErties, {...})
```

不改 `initProps()`、不动道具表，只保证 folder 永远有值。

### 2. `macro <<br>> does not exist`（①保意图）

**根因**：不是 passage，也不是我们的翻译。
`mods\LocationsExt_v1.8.1.zip` 的 `boot.json` 里，TweeReplacer 补丁写成了：

```json
"findString": "<<set $eventskip to 0>>",
"replace": "<<br>><<roadicon>><<link [[快速旅行（乡间道路）|Farm Fast Travel]]>><</link>><br><<set $eventskip to 0>>"
```

开头 `<<br>>` **多了一个 `<`**（应为 `<br>`）。补丁在运行时注入 Harvest Street 后，`<<br>>` 被当成宏 → 报错。

**定位法（可复用）**：
1. 静态 index 搜 `<<br>>` = 0、模组 ZIP 搜 = 0 → 说明是运行时注入
2. CDP 里打印 `Story.get("Harvest Street").text`，拿到注入后的真实文本
3. 用注入文本里的**独特中文串**（`快速旅行（乡间道路）`）回搜模组 → 命中 `boot.json`

**修法**：改 index 内嵌的 LocationsExt 模组 ZIP（`modDataValueZipList` 里的 base64）：
`\u003c\u003cbr\u003e\u003e` → `\u003cbr\u003e`，**9 处**（该模组所有补丁里的同一笔误），重新打包写回。

**校验**：`harvestHasBr = 0`（改前 1）。

### 3. `large胸部` / `massive胸部`（①保意图）

**根因**：`setup.breastsizes` 是**英文数组**

```js
<<set setup.breastsizes to ["", "budding", "tiny", "small", "pert", "modest", "full", "large", "ample", "massive", "huge", "gigantic", "enormous"]>>
```

十几处拼接直接用它：`setup.breastsizes[v] + "胸部"`、`"$_breastSize乳房"` → `large胸部`。

**判据**：全库 `breastsizes[x] is "..."` / `=== "..."` / `includes("...")` 均为 **0 处** → 无逻辑比较，可安全改内容。

**修法**：数组换成中文（索引不变，所有拼接点自动生效）：

```
["", "含苞", "娇小", "小巧", "挺立", "适中", "丰满", "浑圆", "傲人", "硕大", "巨硕", "惊人", "宏伟"]
```

---

### 4. `Export` 按钮（①保意图）

**根因**：4 处玩家可见的 UI 文本仍是英文（存档导出、服装编辑器、IronMan）。
其中 `exportOutfit()` 里有 `setTimeout(() => element.text = "Export", 2000)`，**2 秒后把已翻好的"导出"又改回英文** —— 这就是截图里第一个区块是 `Export`、后面是"导出"的原因。

**修法**：4 处文本替换（`.text("Export")` / `element.text = "Export"` / `value="Export"` / `label: "Export"`），
不动 lodash 的 `Export` 与注释。

---

### 5. NPC 称呼 `slenderman` / `lissomeman` / `glowing tentacle`（①保意图）

**根因**：`<<person>>` widget 用 `$description` 精确匹配 `setup.NPCTitleList_cn_name`（`en,cn|en,cn` 字符串），
这三个 key 不在表里 → 回落 `$description`（英文）。`cultist` 其实**在表里**（`cultist,异教徒`），
截图里的 `cultist` 属于该 NPC 走了别的分支（未复现，留观察）。

**修法**：表尾追加

```
|slenderman,瘦长鬼影|lissomeman,柔影|glowing tentacle,发光触手
```
