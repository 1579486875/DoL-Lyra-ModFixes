## 五、模组之间的联动（重点）

### 5.1 依赖链（谁离不开谁）

```
ModLoader
├─ ModLoaderGui
├─ ImageLoaderHook
├─ TweeReplacer ──┬─ 几乎全部内容模组
│                 └─ 我们的 13 个修复模组
├─ ReplacePatcher
└─ maplebirch ──┬─ MapleBirchCE
               ├─ BasicNeeds
```

**关键**：**TweeReplacer 是 90% 模组的共同依赖**，它坏了全盘崩溃。

### 5.4 图片资源层：**零冲突**

**64 个模组提供的图片路径，没有任何重叠**（0 个冲突）。

这说明：
- **服装/头像/图标资源是"互补"而非"覆盖"**
- 唯一的覆盖是 **Lyra 打包时 BESC 替换原版 `img/`**（不在模组层）
