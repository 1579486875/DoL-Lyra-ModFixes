## 一、`_args[N]` 泄漏到正文（14 处）

### 为什么这是 bug

`_args` 是 `<<widget>>` 的参数数组。**SugarCube 不会像 `_var` 那样自动求值 `_args[N]`** ——
它只在 `<< >>` 宏里可用，**直接写在正文里会输出字面字符串**。

```do
<!-- 错：玩家会看到「露出癖 _args[0]」 -->
<span @class="_classList">露出癖 _args[0]</span>

<!-- 对 -->
<span @class="_classList">露出癖 <<= _args[0]>></span>
```

### 修掉的 14 处

| passage/widget | 原文 | 玩家会看到 |
|---|---|---|
| `exhibitionist` | `露出癖 _args[0]` | `露出癖 _args[0]` |
| `combatpromiscuous1` | `淫乱 _args[0]` | `淫乱 _args[0]` |
| `deviant1` | `异种癖_args[0]` | `异种癖_args[0]` |
| `combatpromiscuous2` | `- 淫乱 _args[0]` | 同上 |
| 抓手动作 | `<<He>>握住你的_args[1]臂。` | `他握住你的_args[1]臂。` |
| 烹饪 | `食材"_args[0]"不包含在可烹饪配方中` | 字面 |
| 烹饪 | `食物"_args[0]"缺少考核描述！` | 字面 |
| 未知 | `<<else>> _args[0]` | 单个 `_args[0]` |

| 选项校验 | `选项无效：_args[0]` | 字面 |

### 为什么之前扫不到

**`_args` 看起来像普通变量**，而我之前的「变量泄漏」判据只扫 `$大写开头` 和 `_小写开头`，
`_args[0]` 带方括号，**不匹配变量名正则**。

## 二、双重转义 `&amp;lt;`（21 处）⚠️ 更严重

### 现象

```
&amp;lt;&amp;lt;link [[离开|Asylum Depths Tunnel 4 Leave]]&amp;gt;&amp;gt;&amp;lt;&amp;lt;/link&amp;gt;&amp;gt;
```

**玩家会看到字面的 `<<link [[离开|...]]>>`，而不是可点击的链接** —— 整个出口消失。

### 根因

`idx` 在构建过程中被 **escape 了两次**：
```
<       →  &lt;   →  &amp;lt;
```

某个脚本对**已经转义过的内容**又做了一次 `html.escape`。

### 修法

```python
data = data.replace("&amp;lt;", "&lt;")
data = data.replace("&amp;gt;", "&gt;")
```

**一条 replace 就修完 21 处。**

### 分布

```
13 处 &amp;lt;
 7 处 &amp;gt;
```

集中在 `Asylum Depths Tunnel` 系列（精神病房隧道）、分页控件。
