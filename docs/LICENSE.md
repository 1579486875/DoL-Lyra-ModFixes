## 本模组做什么

`美化修正` 是一个**图片覆盖工具**，用于调整美化资源与游戏服装的对齐问题。

它提供：
- 一个侧栏入口（`StoryCaption` 里的「美化修正」按钮）
- 一个可视化编辑器，可以对 `img/clothes/`、`img/face/`、`img/hair/` 下的素材做
  位移、缩放、局部变形
- 修改结果存在浏览器本地（IndexedDB），**不改动游戏原始文件**
