## 三、本轮两个新维度的结论

### 3.1 DOM 浮层关闭审计

上一轮修了 `exportOutfit` 的「点空白不关闭」问题（`click` 绑冒泡阶段被 `stopPropagation` 拦）。

本轮把这套判据推广到全库：

- **index**：所有 `document.addEventListener("click", fn)` 均为 `:xxx` 自定义事件或 tooltip，**无冒泡阶段的浮层关闭**。
- **模组**：仅 `more useful foodstuff` 的 `food-effects.js` 有 `document.addEventListener('click', outsideHelp)`（帮助弹窗点外部关闭）。
  - 它用 `e.target.closest('.dfe-help-holder, .dfe-help-portal')` 判断是否在浮层内，逻辑正确。
  - 帮助弹窗不在 overlay 里，被 `stopPropagation` 拦的概率低。
  - **判定：低风险，暂不修改**（避免无谓改动模组）。

### 3.2 未初始化变量属性访问审计

`$Phone.TaskDanger` 那类问题的判据：**`$A.B` 读取但 `$A` 从未 `<<set $A to ...>>`**（会抛 TypeError 而非返回 undefined）。

全库扫描结果：127 个两级访问未 set，逐条核查后：

| 类别 | 数量 | 判定 |
|---|---|---|
| JS 内置对象（`$Array`/`$Object`/`$Error`…） | ~20 | 误报（`$` 是 JS 标识符的一部分） |
| `$_xxx` 临时变量 | ~15 | 误报（SugarCube 私有变量，用 `<<set _x>>` 定义，正则只匹配 `$`） |
| jQuery 对象（`$body`/`$box`/`$backward`…） | ~90 | 误报（`$(...)` 返回值） |
| **真正的 SugarCube 变量** | **0** | **未发现真隐患** |

**结论**：`$Phone` 是本项目唯一的真·未初始化属性访问案例，已在上轮修复，**无同类残留**。
