## 二、本轮修复

### 2.1 【真 bug·已修】NPC title 共 10 个显示英文

**根因**：

```js
st.NPC_CN_NAME  = function (x) { return look(nameTable(), x); };
st.NPC_CN_TITLE = function (x) { return look(typeTable(), x); };   // ← 用的是物种表
```

`NPC_CN_TITLE` 查的是**物种表** `setup.NPCTypeList_cn_name`（248 条，全是 `human,人类` 这类），而 NPC 的 `title` 是 `alpha` / `mayor` / `smuggler` 这类词 —— **表里没有，原样返回英文**。

**实测缺失**（11 个 title 里 10 个）：

| title | 修复前 | 修复后 |
|---|---|---|
| alpha | alpha | 头狼 |
| photographer | photographer | 摄影师 |
| mayor | mayor | 镇长 |
| farmhand | farmhand | 农场工 |
| terror | terror | 恐怖 |
| smuggler | smuggler | 走私者 |
| faithful | faithful | 忠贞者 |
| reflection | reflection | 倒影 |
| captain | captain | 船长 |
| horror | horror | 恐魔 |

**修法**：把这 10 条追加进 `setup.NPCTypeList_cn_name`（`NPC_CN_TITLE` 与物种名共用此表，追加不影响物种解析）。

**运行时验证**：

```
alpha → 头狼      mayor → 市长      smuggler → 走私者
captain → 船长    horror → 恐怖者   farmer → 农场主
```

`Widgets Bodywriting` 用 `setup.NPC_CN_TOOLNAME($NPCList[_n].lefttool)` 显示书写工具，但对照表里**没有 `"pen"`**。

已补：`pen` / `pencil` / `marker` / `brush` / `crayon` / `quill` / `chalk`。

**运行时验证**：`pen → 笔`、`pencil → 铅笔`、`marker → 马克笔`。

### 2.3 【已修】`Lissomeboy` 显示英文

`<<combatPersons>>` 里：

```twee
<<set _text_output to ($description_CN || $description) + "男人">>
```

战斗中新生成的 NPC 没赋值 `description_CN` → 回落英文 `lissome`。

已改成三级兜底（3 处）：

```twee
($description_CN || setup.description_CN($description) || $description)
```

**运行时验证**：`lissome → 柔韧`、`slender → 苗条`、`curvy → 曲线玲珑`。
