## 1. 关键发现：index.html 的真实形态

**`index.html` 是「passage 标签明文 + 内容 HTML 转义」**：

```html
<tw-passagedata name="Start" ...>&lt;&lt;if $x&gt;&gt;...&lt;&lt;/if&gt;&gt;</tw-passagedata>
```

- passage 标签：**明文** `<tw-passagedata>`
- passage 内容：**转义** `&lt;&lt;if`

**这解释了之前两次事故**：
- `6014337C`（全转义）：连 `<tw-passagedata>` 都变成 `&lt;tw-passagedata&gt;` → 0 passage → 白屏
- 我按「明文」写的修复脚本（`ZZ02`/`Z03`/`A26`/`B04`/`C04`）**在转义形态下全部失效**

**修复方案**：统一用 `html.escape(old)` / `html.escape(new)` 做替换，兼容两态。
新脚本 `D01_fix_all_escaped.py` 替代了那 5 个旧脚本。
