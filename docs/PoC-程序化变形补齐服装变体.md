# PoC 结果：程序化变形补齐服装尺寸变体

**日期**：2026-11-27
**对象**：`corset`（束腰）
**结论**：**技术可行，但适用面有限**——小配件效果好，大件服装需要更复杂的变形。

---

## 一、PoC v1：整体缩放（失败）

**做法**：把整张 `corset/1.png` 围绕画面中心等比缩放。

**结果**：

| 图 | 观察 |
|---|---|
| `corset_1_原始.png` | 左右两个小块，间距约 230 像素 |
| `corset_0.png`（v1） | 两个小块**被拉近了**，间距明显缩小 |

**失败原因**：服装图是**左右两块**（对应左右两侧），整体缩放会把**间距**也一起缩放，
导致**位置错位**。

---

## 二、PoC v2：分块缩放（成功）

**做法**：
1. 用 alpha 通道做**连通域分析**，识别出左右两个块
2. 对每个块**围绕各自中心**缩放
3. 其他区域保持透明

**实测数据**：

```
corset/1 连通块: [(105, 95, 130, 119), (361, 95, 386, 118)]
corset/4 连通块: [(105, 101, 130, 119), (361, 99, 386, 118)]

胸宽: 0=0  1=275  4=386  5=399
缩放系数: 1→0 = 0.75(下限)  4→5 = 1.034
```

**结果**：

| 图 | 观察 |
|---|---|
| `corset_0.png` | 两块**位置不变**，尺寸缩小 25% ✅ |
| `corset_5.png` | 两块**位置不变**，尺寸放大 3.4% ✅ |

**位置正确、比例正确**。

## 三、可行性评估（诚实版）

### 3.1 适用范围

| 服装类型 | 分块缩放效果 | 说明 |
|---|---|---|
| **小配件**（束腰、项圈、手环、戒指、耳环） | ✅ **好** | 独立小块，缩放不破坏结构 |
| **中等服装**（胸罩、内衣、短袜） | ⚠️ 一般 | 形状简单，缩放基本可用 |
| **大件服装**（上衣、裙子、外套、连体衣） | ❌ **不行** | 缩放会**拉伸纹理、破坏褶皱和扣子** |

**原因**：大件服装不是"独立小块"，而是一整片连续图形，
等比缩放会让**布料纹理、纽扣、缝线**全部变形。

### 3.2 数据支撑

我们包里的 265 个有变体的服装中：

- **小配件类**（hands / neck / handheld / feet / rings / earrings）：约 **60 个**
- **中等**（under-upper / under-lower）：约 **40 个**
- **大件**（upper / lower / over-upper / over-lower）：约 **165 个**

**分块缩放只能覆盖前 100 个（38%）**，剩下 165 个大件需要别的办法。

### 3.3 大件的正确做法

对大件服装，**必须用局部变形（warp）而不是整体缩放**：

```
1. 取胸部图的 alpha 轮廓（breasts-4 → breasts-5）
2. 计算两轮廓之间的位移场（光流 / 最近邻匹配）
3. 只对服装的「胸部区域」应用位移场
4. 胸部以外的区域（袖子、下摆、扣子）保持不动
```

**技术难点**：
- 位移场估计要足够平滑
- 需要**区域蒙版**（只变形胸部一带）
- 变形后要**修边缘像素**

**工作量**：每个大件 15–30 分钟（半自动 + 人工修）。

## 四、下一步建议（三条）

### 路线 1：只补小配件（低成本，快）

**范围**：约 100 个小/中件
**方法**：分块缩放（PoC v2 已验证）
**工作量**：脚本 2 小时 + 抽查 1 小时
**效果**：束腰、项圈、手环、内衣等**立刻贴合**

### 路线 2：小配件 + 大件局部变形（完整，慢）

**范围**：265 个全部
**方法**：分块缩放 + 位移场 warp
**工作量**：脚本 1 天 + 人工修 2–3 天
**效果**：全部贴合

### 路线 3：只修最常用的 10–20 件（性价比最高）

**范围**：束腰、胸罩、泳装、校服、常见外套
**方法**：手动 + AI 辅助精修
**工作量**：每件 30 分钟，共 5–10 小时
**效果**：日常穿的都贴合

## 六、判断

**程序化变形能解决 38% 的服装（小/中件）**，
剩下 62%（大件）需要"局部变形 + 人工修"。

**AI 的定位**：
- 不用于批量重绘（风格一致性差）
- **用于补"完全缺失"的变体**（如 `6.png` 这种一张都没有的）
- **用于修变形后破损的边缘**

**推荐先做路线 3**（最常用的十几件），
验证效果后再决定要不要铺开到全部 265 个。
